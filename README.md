# Sales Performance Analysis Dashboard (2022–2025)

## Project Overview
This project focuses on analyzing sales transaction data from 2022 to 2025 using Microsoft Power BI. The dashboard helps explore sales performance, profitability, customer information, product categories, order status, and returns through interactive visualizations.

## Project Objectives
- Analyze overall sales and profit performance.
- Understand sales trends over time.
- Compare sales across regions and product categories.
- Analyze customer segments and sales channels.
- Explore order status and product returns.
- Present key business metrics through an interactive dashboard.

## Dataset Information
The project uses two CSV files:

1. `sales_transaction_2022_2025.csv` – Main sales transaction dataset.
2. `sales_data_dictionart.csv` – Data dictionary describing the dataset columns.

- Period: 2022–2025
- Records: Approximately 18,045 transaction rows
- Columns: 36

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV datasets

## Project Workflow
1. Imported CSV files into Power BI.
2. Explored the dataset and data dictionary.
3. Cleaned and transformed data using Power Query.
4. Created a date table and established a relationship with the sales data.
5. Created DAX measures for key performance indicators.
6. Designed an interactive dashboard with charts, KPI cards, and slicers.
7. Tested the report interactions and filters.

## Key Performance Indicators
