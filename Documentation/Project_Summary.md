# Project Summary

## Project Name
Sales Performance Analysis Dashboard (2022–2025)

## Objective
To analyze sales transactions and understand business performance using Power BI.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- CSV datasets

## Main Activities
1. Data exploration
2. Data cleaning and transformation
3. Date table creation
4. Data modelling
5. DAX measure creation
6. Interactive dashboard development

## Dashboard Components
- Five KPI cards
- Ten visualizations
- Four interactive slicers

## Key Metrics
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Average Customer Rating

## Outcome
Created an interactive sales performance dashboard to analyze sales, profitability, products, regions, customers, and returns.
